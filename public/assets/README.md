## Image Guidelines

### Format
- Use JPG for photos (profile, projects)
- Use PNG for icons and graphics with transparency
- Use WebP for better compression (optional)

### Optimization
- Compress images before uploading
- Recommended tools:
  - TinyPNG (https://tinypng.com/)
  - Squoosh (https://squoosh.app/)
  - ImageOptim (Mac)

### Dimensions
- Profile: 300x300px (square, centered face)
- Projects: 800x600px (landscape, 4:3 ratio)
- Social previews: Follow platform specifications
- PWA icons: Must be square

### File Naming
- Use lowercase
- Use hyphens for spaces
- Be descriptive
- Examples: `profile-photo.jpg`, `project-ecommerce.jpg`

## Placeholder Images

While developing, you can use placeholder services:
- https://via.placeholder.com/300x300
- https://picsum.photos/800/600
- https://placehold.co/800x600

Replace these with your actual images before deployment.
